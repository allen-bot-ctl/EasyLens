# 0.1.13 应用图标：mac 和 Windows 改用 EasyLens 眼睛图标（老板 2026-11-22 01:32 北京时间）

## 现状（feat/gbot @ v0.1.12）
- 「应用程序」文件夹、程序坞、dmg 里显示的都是 Electron 默认图标。
- 原因：package.json 里只有 `linux` 配了 `icon: electron/assets/icon.png`，`mac` 和 `win` 都没配。
- 现有 `electron/assets/icon.png` 只有 256×256，且没有矢量源文件。mac 至少要 512px，最好 1024px。

## 改法（唯一方案）
1. **重绘源图**（mind 已交付）：按现有 icon.png 1:1 重绘，绘制脚本在 `build/icon-src/draw.py`，以 4 倍尺寸绘制后缩小。构图、颜色都不改：深色圆角底、白色眼眶弧线、放射状虹膜、中心白圈黑点、左侧红点粉晕。
2. **导出图片**（mind 已交付）：`build/icon.png`（1024×1024）。按 macOS 图标网格，主体圆角方块是 824×824，居中，四周留 100px 透明边，圆角半径约 185px。这样它在程序坞里和其他 App 一样大，不会显得偏大。
3. **配置**：
   - package.json 的 `mac.icon`、`win.icon`、`linux.icon` 都指向 `build/icon.png`，由 electron-builder 生成 icns 和 ico；
   - `electron/assets/icon.png`（关于窗口等运行时还在用）和 `site/assets/icon.png` 都换成新导出的图（512px）。
4. **不动的部分**：托盘图标 `tray.png`（菜单栏模板图）不改，签名和升级机制也不改。

## 验收
- I-C1 CI：两种芯片的 .app 里都有 `Contents/Resources/icon.icns`，并且含 1024 尺寸（`iconutil` 或 `sips` 可读）。Windows 的 exe 用的是新 ico。
- I-C2 CI：0.1.12 的签名校验全部照旧通过，designated 和钉死的那一行逐字一致。
- I-C3 更新源：用 0.1.12 查两种芯片，返回 0.1.13 的 zip。发布后约 10 分钟内可能仍是 204，那是缓存。
- 真机（老板），一次走完：
  - ① 0.1.12 在托盘点「检查更新…」→「重启以更新到 0.1.13」→ 版本显示 0.1.13；
  - ② 屏幕录制和辅助功能仍是「已授权」；
  - ③ 「应用程序」文件夹和程序坞里显示眼睛图标。Finder 有图标缓存，如果还是旧图标，先退出再重开 EasyLens，或者等一会儿。

## 不做
不重新设计图标，不改托盘图标。
