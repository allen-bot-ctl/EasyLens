# v0.1.15 工程整理

- 固定依赖 Electron 43.8.12：当前仍受支持，保留 macOS 12 运行时下限和 Intel x64；原 Swift 选区工具仍以 macOS 13 为编译下限。Electron 44 起不支持 macOS 12；[官方计划](https://releases.electronjs.org/schedule)显示 43 分支支持预计于 2027-01-05 结束，应届时前复核 macOS 12 使用需求与长期版本方案。详见 [Electron 兼容变化](https://www.electronjs.org/docs/latest/breaking-changes/#removed-macos-12-support)。
- 保留现有 EasyLens 自签叶证书和 bundle identifier，不换钥、不启用公证、不改变 TCC 稳定身份。ZIP SHA-256 仍校验传输一致性，但下载后的应用和内置选区工具还必须通过 macOS codesign 验证，匹配固定证书；主应用同时必须满足既有 identifier。验证覆盖新下载与缓存复用，分离的安装脚本在替换前再次验签。签名失败不自动推荐同一发布的 DMG。
- 首次从 v0.1.14 进入 v0.1.15 仍执行旧更新器；新校验不可能回溯保护旧更新器。可通过发布页手动下载 DMG。稳定签名不等于 Apple Developer ID 或公证。
- 拆开 SwiftTests 与 Node tests 目录，避免大小写不敏感文件系统冲突；将此前未被测试 glob 覆盖的 OCR 预处理测试移入 Node tests。
- macOS CI 应使用实际签名包及无固定签名的临时副本验证策略；覆盖集成验证不等于在用户 Mac 完成系统授权、安装和重启。
