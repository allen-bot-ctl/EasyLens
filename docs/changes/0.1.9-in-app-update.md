# 0.1.9 EasyLens 应用内升级（与栏历同一套）——老板 2026-11-21 23:38

## 现状（feat/gbot @ 973f2b9）
- 没有任何应用内升级：没有检查更新入口，也没有更新源和自更新。
- 签名：`mac.identity: null`，等于临时签名，`macos-selection-reader` 也是 `codesign -`。每次构建 cdhash 都会变，屏幕录制和辅助功能这**两项**授权升级后都会丢。
- v0.1.8 的 tag 打在 master（d05bc16）上。feat/gbot 从 d05bc16 往前又有 13 个提交，还没发过版。
- 产物：mac 有 x64 和 arm64 两种 dmg/zip，另外还有 Windows 的 exe 和 Linux 的 AppImage。没有 .sha256，也没有 release-notes。

## 目标
装过一次以后，每次出新版，用户都能在托盘里一键升级，而且升级后屏幕录制和辅助功能都不用重新授权。

## 改法（唯一方案，照搬栏历 allen-bot-ctl/lan-li master）
1. **更新源**：照搬 `electron/update-feed.js`、`updater.js`、`update-status.js`，仓库改成 allen-bot-ctl/EasyLens。启动时检查一次，之后每 6 小时检查一次；自动检查不出声，自动下载。
2. **自更新（macOS）**：照搬 `electron/mac-self-update.js`，改这几处：
   - `APP_NAME = 'EasyLens.app'`，STAGING/BACKUP 前缀改成 `.EasyLens-`；
   - `SUPPORTED_ARCH` 改为同时支持 x64 和 arm64，按 `process.arch` 选对应的 zip；
   - `UPDATE_FILE_RE = /^EasyLens-(\d+\.\d+\.\d+)-mac-(x64|arm64)\.zip$/`。
   流程不变：下载 zip，用同名 .sha256 校验，ditto 解压，核对 CFBundleShortVersionString，退出后由脚本替换并重启。任何一步失败都回退为打开对应架构的 dmg 下载地址。不用 Squirrel.Mac。
3. **Windows / Linux**：只做检查，不做自更新。发现新版时托盘出现「下载新版本 X」，点击后打开 Release 页面。
4. **固定签名**：照搬栏历 0.1.52 的做法。
   - 新建一张自签证书「EasyLens Self-Signed」，有效期 10 年。p12 只放在 GitHub Secrets（`EASYLENS_SIGN_P12` / `EASYLENS_SIGN_PASSWORD`）和 coder 本机，不和栏历共用。
   - CI 先签 `electron/bin/macos-selection-reader`，再签整个 .app，两者都用这张证书。
   - 签名校验：Authority 必须是「EasyLens Self-Signed」；designated 必须是 `identifier "ai.nangua.EasyLens" and certificate leaf = H"<sha1>"`，和 `build/expected-designated.txt` 逐字一致；`--verify --deep --strict` 必须通过。
5. **发布**：
   - release.yml 给每个 mac zip 生成 `.sha256` 并上传；
   - 发版说明从 `release-notes/vX.md` 读取，缺了这个文件就让发版失败（不再套用模板）；
   - 以后 tag 只打在 feat/gbot 的提交上，master 不再在这个仓库发版，免得更新源拿到 Swift 版。
6. **托盘菜单**：在「关于 EasyLens」上方插入以下内容，状态表见下文。
   - `检查更新…`
   - 灰字 `版本 0.1.9`

**签名切换带来的权限状态：**
- 0.1.8 → 0.1.9 只能手动装 dmg（0.1.8 没有升级功能），而且要重新授权屏幕录制和辅助功能各一次。托盘上现有的「未授权（点击授权）」两行就是入口，不另做。
- 0.1.9 → 0.1.10 以后，在应用内升级，两项授权都保留。

## 验收
- U-C1 单测：照搬栏历的 updater 和 mac-self-update 测试，并补上 arm64 和 x64 两种架构选 zip、sha256 不一致时回退 dmg、文件名正则这几项。
- U-C2 CI：Release 里有 x64 和 arm64 各自的 dmg、zip、zip.sha256，以及 win exe、linux AppImage；说明来自 release-notes/v0.1.9.md。
- U-C3 CI：签名校验三项都通过；对 selection-reader 运行 `codesign -dv`，Authority 同样是 EasyLens Self-Signed。
- U-C4 更新源：`update.electronjs.org/allen-bot-ctl/EasyLens/darwin-arm64/0.1.9` 和 `darwin-x64/0.1.9` 都返回 204。
- **U-C5 验证版**：0.1.9 发版后，紧接着发 0.1.10，只改版本号和发版说明。之后 `darwin-*/0.1.9` 都要返回 200，notes 是 0.1.10 的。
- 真机（老板）：
  - ① 手动装 0.1.9 的 dmg，授权屏幕录制和辅助功能；
  - ② 托盘「检查更新…」→ 下载 → 点「重启以更新到 0.1.10」→ 版本显示 0.1.10；
  - ③ 升级后屏幕录制和辅助功能都还是「已授权」，眼睛和划选翻译能直接用。
