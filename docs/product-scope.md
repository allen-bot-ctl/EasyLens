# 产品范围

## 当前迭代

EasyLens 首先服务于 macOS 15+ 的英文阅读：用户从菜单栏或通过 ⌃⌥L 唤出眼睛，眼睛始终贴近鼠标；中心落在英文单词上时显示中文。若鼠标中心位于实时选区内，优先翻译完整选区。Esc 隐藏。中文等非英文内容不进入翻译流程。

应用目前通过 ScreenCaptureKit 获取鼠标附近画面，Vision 做 OCR，Accessibility 核实选区。翻译来源默认是 macOS Translation 本地英译中；菜单栏设置中也可配置 DeepSeek API 的接口地址、模型和密钥，并切换焦点词及完整选区翻译来源。密钥保存在 `~/.easylens/deepseek-api-key`（权限 `0600`）；选用 DeepSeek 时，待译文字会发送到所配置的 HTTPS 接口。眼睛的中央保持透明；识别与翻译异步进行。未命中缓存的远端请求若超过短暂等待时间，会显示中性的“正在转译”卡片；翻译成功时内圈与眼珠纹路才变黄。以上是已实现的工程路径，不意味着所有第三方应用和字体都已验证。

使用本地翻译时可能需要下载英语与简体中文的系统翻译资源。EasyLens 查询就绪状态，缺失时提供说明和下载入口，实际下载确认由 macOS 执行；资源就绪前暂停本地翻译请求。DeepSeek 翻译使用用户配置的 API Key，独立于本地语言资源。屏幕识别需录屏授权，完整选区翻译另需辅助功能授权；首次唤醒时提供对应说明和系统设置入口，菜单栏显示两项授权状态。

## 当前边界

- 目前仅接入 DeepSeek 云端翻译，不持久化截图；云端仅接收待译文字，不接收截图。
- 只提供本地开发签名的构建；正式发布签名、公证、安装包和自动更新尚未实现。
- 屏幕读取与辅助功能权限由 macOS 管理；不同应用的选区辅助可用性仍需持续验证。
- 花纹、Logo、人物等识别类型属于后续探索，不据此预设框架。

工程结构与验证记录见 [engineering.md](engineering.md)。
