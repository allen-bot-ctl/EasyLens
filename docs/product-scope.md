# 产品范围（初始化草案）

## 产品定位

EasyLens 是以桌面客户端呈现的 AI 识别产品。交互意象参考系统放大镜与本机 iShot 的快捷键唤起体验：快捷键唤起一个小型遮罩窗口，窗口覆盖位置下方的内容成为识别对象。这是体验目标，不表示复用 iShot 的实现或已经确认具体窗口行为。

## 第一个敏捷迭代：英译中

预期用户路径：

1. 用户按快捷键唤起识别窗口，并将其放在目标内容上方。
2. 客户端获取该位置下方的画面，识别文字。
3. 对识别结果进行语言判断。英文内容进入英译中；非英文内容跳过后续翻译执行。
4. 用户在客户端看到中文结果。

首个迭代的成功标准是上述路径在选定目标平台上能够真实走通，并能验证非英文内容没有进入翻译流程。窗口尺寸、定位、结果展示、混合语言内容的处理粒度以及失败提示，需要在原型实验中细化。

## 后续方向

花纹、Logo、人物等形态可能使用同一覆盖区域作为输入，但识别目标、输出与交互仍需单独调研。当前不实现，也不为这些形态预设统一模型、插件机制或数据结构。

## 待调研与决策

- 首发平台和跨平台范围，以及全局快捷键、悬浮窗口、屏幕读取所需权限。
- 遮罩窗口如何显示和移动，以及如何获取其覆盖位置下方的原始画面。
- OCR 质量、英文判定规则、英文与非英文混排时的跳过粒度。
- 翻译的本地或远程方案、延迟、成本和隐私边界。
- 结果呈现、可访问性、取消操作及异常处理。

以上均为开放问题；应以调研和可复现实验确定方案，不在初始化阶段定技术栈。
