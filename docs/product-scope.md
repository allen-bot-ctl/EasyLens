# 产品范围

## 当前迭代

EasyLens 首先服务于 macOS 15+ 的英文阅读：用户从菜单栏或通过 ⌃⌥L 唤出眼睛，眼睛始终贴近鼠标；中心落在英文单词上时显示中文。若鼠标中心位于实时选区内，优先翻译完整选区。Esc 隐藏。中文等非英文内容不进入翻译流程。

应用目前通过 ScreenCaptureKit 获取鼠标附近画面，Vision 做 OCR，Accessibility 核实选区，Translation 做本地英译中。眼睛的中央保持透明；识别与翻译异步进行。翻译成功时内圈与眼珠纹路变黄。以上是已实现的本地工程路径，不意味着所有第三方应用和字体都已验证。

首次使用可能需要下载英语与简体中文的系统翻译资源。EasyLens 查询就绪状态，缺失时提供说明和下载入口，实际下载确认由 macOS 执行；资源就绪前暂停翻译请求。完整选区翻译另需辅助功能授权；首次唤醒时提供说明和系统设置入口，菜单栏显示授权状态。

## 当前边界

- 不接入云端 LLM，不持久化截图。
- 只提供本地临时签名的开发构建；正式发布签名、公证、安装包和自动更新尚未实现。
- 屏幕读取与辅助功能权限由 macOS 管理；不同应用的选区辅助可用性仍需持续验证。
- 花纹、Logo、人物等识别类型属于后续探索，不据此预设框架。

工程结构与验证记录见 [engineering.md](engineering.md)。
