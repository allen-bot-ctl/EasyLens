不打断阅读的翻译方式

没有需要切换的窗口，也没有复制粘贴。眼睛跟着鼠标走，中文在指针旁边展开。

  1. 01
    Ctrl+Alt+L

    唤出眼睛

    全局快捷键随时显示透明眼睛，不需要先打开主窗口。也可以从托盘菜单显示。

  2. 02

    对准英文

    眼睛跟随鼠标移动，停稳后截取附近画面并识别英文。中心词优先，选中文字时翻译完整选区。

  3. 03
    Esc

    继续手头的事

    按 Esc 隐藏眼睛。截图默认不落盘，翻译来源和 DeepSeek 设置都在托盘里管理。

主要能力

为英文阅读准备的一只小工具

离线优先，边界坦率。能用本地数据完成的，就不必把内容发到远端。

约 2.6 万词的离线词典

随包内置 ECDICT 英文词条子集，共 26,282 条；支持基本词形还原。查不到时明确显示未收录，不编造译文。

无需联网

屏幕 OCR

使用随包的 Tesseract 英文数据识别鼠标附近的屏幕文字。截图只在本机处理。

选区优先

当前选区包含焦点词时，优先翻译完整选区；没有可用选区再退回单词。Linux 使用 PRIMARY/剪贴板回退。

可选 DeepSeek

需要更通顺的长句译文时，可在设置中启用 DeepSeek。自填 HTTPS 接口、模型和密钥，只发送待译文字。

托盘常驻

启动后只驻留托盘，不占任务栏。托盘菜单可以显示眼睛、打开设置或退出。

隐私边界清楚

默认不保存截图；只有设置 EASYLENS_DEBUG_CAPTURE=1 才会写入临时目录用于诊断。

使用方式

记住三个键就够了

启动后 EasyLens 待在托盘里。按 Ctrl+Alt+L 显示或隐藏眼睛，移动鼠标对准英文，按 Esc 收起。右键托盘图标可以打开「设置…」。

  • Ctrl + Alt + L 唤出 / 隐藏跟随鼠标的眼睛
  • Esc 隐藏眼睛，不退出应用
  • 托盘设置 切换离线词典 / DeepSeek，填写接口和密钥，测试连接

DeepSeek 密钥保存在 ~/.easylens/deepseek-api-key（目录 0700、文件 0600），不会写进仓库或安装包。

常见问题

先把边界说清楚

默认需要联网吗？

不需要。单词查询默认使用随包的离线词典。只有主动切换到 DeepSeek 并保存密钥后，待译文字才会发送到你配置的 HTTPS 接口。

会把我的屏幕截图上传吗？

不会。屏幕捕获和 OCR 在本机完成，截图默认不持久化。启用 DeepSeek 时，远端只接收待译文字，不接收截图。

为什么目前只有 Linux 版本？

当前只验证了 Linux 上的 Electron 入口。macOS / Windows 的 Electron 安装包尚未提供；仓库里的 macOS Swift 工程仅作为早期行为参考。

托盘图标没有出现？

部分 Linux 桌面需要 AppIndicator / StatusNotifier 扩展才能显示托盘图标。眼睛仍然可以通过 Ctrl+Alt+L 唤出。

识别不到屏幕上的英文？

OCR 精度受字体、分辨率、暗色界面和排版影响。Wayland 下屏幕捕获依赖 PipeWire/portal，若捕获为黑屏，优先在 X11 会话中运行。

词典查不到某个词怎么办？

内置词典是 ECDICT 子集，查不到时会明确提示未收录，不会编造释义。长句或专业内容可以在设置中启用 DeepSeek。
